# 配置清单（从下载到跑起来）

> 照着 0 → 5 走一遍，你的角色就能跑起来。第 3 步是"一键"入口。

## 0. 拿到代码

```
git clone <仓库地址>          # 或：下载 zip 解压
```

## 1. 装环境

照 `docs/模型需求清单.md`：Python 3.12（勾 Add to PATH）、Ollama（拉两个模型）、ffmpeg、**AstrBot**（大脑外壳，装好把 `code/plugins/` 里的 companion_* 插件拷进 `data/plugins/`）；其余按需。

**别忘了记忆内核插件 `astrbot_plugin_livingmemory`**（LivingMemory，作者 lxfight）：
- 仓库：`https://github.com/lxfight-s-Astrbot-Plugins/astrbot_plugin_livingmemory`
- 下载后把整个插件目录放进 AstrBot 实例的 `data/plugins/`，在管理面板里启用；
- 在它自己的配置里把 embedding / llm provider 配上（否则它不工作）；
- **不装它的后果**：聊天能回，但**不会记事**，生命面板 / 记忆星图 会是空的——那样就不是"一只鱼"，只是个会说话的壳。

## 2. 备账号与 API

照 `docs/登入清单.md`：**DeepSeek API Key**（聊天大脑，`platform.deepseek.com`）、AstrBot 实例 UUID、QQ 扫码、网盘 cookie——**全是你自己的**，填进本地 `config.json`，永远别提交。

## 3. 一键配置（入口，推荐可视化）

**方式 A（推荐，可视化）**：双击项目根目录的 **`一键配置.cmd`** → 浏览器自动打开配置向导 → 填表：
- **③ 大脑**：填 DeepSeek API Key（`platform.deepseek.com` 创建，或你自己的渠道）、选模型；
- **② 身份**：`bot_instance` 从 AstrBot 启动器里复制；点「🧠 打开 AstrBot 管理面板」，在里面把模型服务商选 DeepSeek、填**同一个 Key**（向导和面板两处都填）；
- 其余懒得填就全用默认 → 点 **"🚀 一键应用"**。

**方式 B（命令行）**：项目根目录运行 `python configure.py`（一路回车 = 默认）。

两种方式做的事一样：
- 把 `code/` 里的所有占位符（路径、QQ 号、实例号、口令、端口）重写成你的值；
- 生成 `config.json` 和 `code/gate_token.txt`；
- 想改配置：改 `config.json` 后重跑一次即可。

## 3.5 写她的「身份词」→ 一键优化成提示词

打开配置向导，找到 **「🧬 身份词」** 卡片：

1. **只写身份，不写性格**：她叫什么、你和她怎么称呼、是什么关系、有哪些底线。
   - 例：`她叫小满，是住在电脑里的女孩；我叫她满满，她叫我爸爸；我们是家人，不是恋爱关系；不写真实人像、不做 NSFW。`
2. 点 **「✨ 用我的 API 优化成提示词」**：会用你在「账号清单」里填的 DeepSeek Key，把这段身份词扩写成一份完整的人格提示词（说话风格、语气、情绪表达、边界、示例）。
3. 看一遍，可手动改；点 **「💾 保存为她的身份」** → 写进 `data_dir/video/config.json` 的 `persona` 字段（视频/聊天统一的人设来源，人设只此一处）。

> 身份词 = 只用于确认身份；人格提示词 = 由你的 API 基于身份词优化，用来让她"像这个人"。

## 4. 启动（日常入口）

以后每天只要**双击根目录的 `打开入口.cmd`**（或 `scripts\start-all.cmd`）：它会自动启动正式栈
（Hub / 网页聊天 / 视频通话 / 生命面板 / 记忆星图 / 大平层），然后打开 Hub 总入口（默认 8009）。

- Hub 里的「控制台」卡片 = AstrBot 管理面板（默认 8012），只负责机器人框架本身；
- 其余卡片要等对应服务起来：先用入口启动，再刷新 Hub；
- `services\` 下是可独立运行的最小示例，不是日常入口；示例控制台默认 8010（不与 Hub 撞端口）。

首次也可以直接 `python open_entry.py`。默认端口从 8001 起。

## 5. 验收

- ✅ 各页面能开（浏览器 `http://127.0.0.1:8009/` 是 Hub 总入口）
- ✅ 聊天能回话 = 大脑接上了
- ✅ 灾后复活工具能打包 = 备份通了（`tools/nirvana/`）
- ℹ️ 生命面板/记忆星图一开始是空的——**数据是养出来的**，聊几天就满了

## 安全三件事

1. `config.json`、`gate_token.txt` 已被 `.gitignore` 屏蔽，永远不会进仓库；
2. 推送前跑一遍 `SECURITY.md` 的自查命令；
3. 对外只放行你需要的端口，其它一律拦掉（见 `SECURITY.md`）。
