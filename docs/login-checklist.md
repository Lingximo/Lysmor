# 登入清单（所有账号/API 都是使用者自己的）

本项目**不含任何账号或密钥**。部署时由**你**逐项准备，全部填进本地 `config.json`
（该文件被 `.gitignore` 屏蔽，永远不要提交）。

## 必须准备的

| # | 账号/API | 用途 | 怎么准备 | 注意事项 |
|---|---|---|---|---|
| 1 | **DeepSeek API Key** | 聊天的大脑（推荐） | 到 `platform.deepseek.com` 注册 → 左侧「API Keys」创建 → 复制 `sk-...` 填进**配置向导「③ 大脑」** | 按量计费；日常用 `deepseek-chat`，要深度思考用 `deepseek-reasoner`（更慢更贵）；注意余额 |
| 2 | 其它 LLM API（可选） | 想换别家大脑 | 任一 OpenAI 兼容服务商均可 | 向导「③ 大脑」里改 provider / base_url / key / model |
| 3 | **AstrBot 实例 UUID** | 机器人框架实例号 | 装好 AstrBot 启动器后，在启动器里复制实例 UUID | 填进配置的 `bot_instance`；**并在 AstrBot 管理面板里把模型服务商选 DeepSeek、填同一个 API Key**（面板端口与向导「②」保持一致） |
| 4 | QQ 账号 | IM 通道 | 自己注册；在 NapCat 上**扫码登录** | QQ 有风控风险，建议不用大号 |
| 5 | 网盘账号 | 灾后备份 | 注册夸克或其它网盘，导出 cookie 填进配置 | cookie 会过期，需定期更换 |
| 6 | 口令（gate token） | 各页面的门禁 | 一键配置自动生成，或自己写一段长随机串 | 只有知道口令的设备能进；别用生日/手机号 |

## 按需准备的（可选）

| # | 账号/服务 | 用途 | 怎么准备 | 注意事项 |
|---|---|---|---|---|
| 7 | 隧道账号 | 外网访问 | 注册蒲公英等，手机/电脑登录同一账号 | 只放行你需要的端口 |
| 8 | HTTPS 证书 | 视频通话加密 | 自签或申请免费证书 | 自签证书需在设备上手动信任 |
| 9 | 语音（edge-tts） | 说话的声音 | 免注册，走微软在线服务 | 留意微软服务条款；想离线可换本地 TTS |

## 部署顺序建议

1. 先配 **DeepSeek API Key + 口令** → 网页聊天就能回话；
2. 再配 **AstrBot + 实例 UUID** → 插件（情绪/记忆等）跑起来；
3. 再配 **QQ 扫码** → IM 通道开通；
4. 再配 **网盘** → 灾后备份跑起来；
5. 隧道和证书按需再上。

## 安全口诀

- 所有凭证只出现在**本地** `config.json` 和 `code/gate_token.txt`；
- 仓库里只有 `config.example.json`（占位符）；
- 推送前跑一遍 `SECURITY.md` 的自查命令。
