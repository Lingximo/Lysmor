# 界面设计

> 本文是**界面结构设计**（布局、功能、交互），不含任何角色形象素材。
> 每个界面里的"角色形象 / 立绘 / Live2D / 表情包"一律由使用者自备。

## 设计原则

1. **一页一功能**，互不混淆：聊天、视频、面板、星图、房间、画廊、控制台各是各的页面；
2. 面板一律**只读**——不提供改写角色状态的入口（状态由后台自行演化）；
3. 对外**数据接口**挂口令门禁（`?t=口令` / `X-Gate-Token` 头）；页面本身是静态壳、不含数据，公开提供；
4. 移动端优先，桌面可用；深色为主、低饱和配色。

## 各页面设计

### 1. 聊天页
- 布局：顶部状态条（在线/情绪摘要）/ 中部对话流 / 底部输入框（文字 + 语音）
- 功能：收发消息、主动消息推送、表情包、清屏、复制
- 交互：输入法组词期间不误发送；回车发送，Shift+回车换行

### 2. 视频通话页
- 布局：左角色画面（摄像头 + 形象挂件）/ 右侧对话与状态条
- 功能：实时视频、语音对话、静音/挂断、画面仅在变化时推送（省流）
- 形象：Live2D / 立绘由使用者放入素材目录，本项目不附带

### 3. 生命面板
- 布局：仪表组（精力 / 饥饿 / 口渴 / 睡眠 / 情绪…）+ 随时间演化曲线
- 功能：只读展示；自动刷新
- 交互：悬停看说明；**无任何编辑入口**

### 4. 记忆星图
- 布局：全屏星图——点 = 记忆，连线 = 关联，按主题聚类
- 功能：缩放 / 旋转 / 悬停查看记忆摘要（摘要由角色自行生成）
- 交互：滚轮缩放、拖拽平移

### 5. 房间（大平层）
- 布局：3D 房间，可切换视角
- 功能：角色在房间中的位置与状态、家具布局
- 交互：点击物品查看说明；布局放配置文件

### 6. 扫码 / 登录页
- 用途：IM 通道扫码登录（展示二维码）+ 各页面口令门禁
- 功能：显示二维码、手动刷新、登录状态提示
- 安全：页面本身同样挂口令门禁；二维码页建议只对内网

### 7. 画廊
- 布局：网格 + 详情页（成品图 + 过程视频）
- 功能：角色产出的画作按时间陈列

### 8. 控制台 / 整合页
- 布局：一页总览（状态、最近记忆、最近行为、各服务健康度）
- 功能：各模块入口聚合；健康检查只读展示
- 交互：卡片点击跳转到对应页面

## 视觉风格建议（供微调）

- 主色板：深海蓝底 + 暖色点缀；避免纯黑纯白；
- 字体：系统字体栈即可；
- 动效：克制——状态变化用 2~3 秒淡入淡出，不做高频闪烁；
- 所有文字文案由使用者按自己的角色改写。
