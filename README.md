# Lysmor

**可自托管的 AI 伴侣系统（开源参考实现）**：长期记忆、情绪与生理状态、多个界面（聊天 / 视频通话 / 生命面板 / 记忆星图 / 房间 / 画廊 / 控制台），以及一套灾后备份与复活工具。

## 这是什么

Lysmor 是一套「AI 伴侣」系统的完整实现骨架：

- **长期记忆**：文档 + 向量检索 + 图记忆，按重要度 / 相关度 / 时间召回；
- **情绪与生理**：情绪、饥饿、口渴、睡眠、精力等状态，驱动语气与行为；
- **多端界面**：网页聊天、视频通话（Live2D 形象自备）、生命面板、记忆星图、3D 大平层房间、画廊、控制台；
- **IM 通道**：经 AstrBot + NapCat 接入 QQ（QQ 本体由使用者自行安装）；
- **灾后复活**：定期整包备份 + 分片上传云端 + 换机一键恢复。

一切都在本地运行：数据、账号、密钥都只存在于使用者自己的电脑上。

## 模块一览

| 模块 | 做什么 |
|---|---|
| 记忆系统 | 长期记忆库（文档 + 向量检索 + 图记忆）；按重要度/相关度/时间召回；只归档不物理删除 |
| 情绪与生理层 | 情绪、饥饿、口渴、睡眠、精力等状态，驱动语气与行为 |
| 网页聊天 | 不依赖 IM 的聊天通道（代码见 `services/webchat/`） |
| 视频通话 | 实时视频 + 语音 + 形象挂件（形象素材由使用者自备） |
| 生命面板 | 生理/情绪状态可视化（代码见 `services/life/`） |
| 记忆星图 | 记忆按主题聚类的可视化星图（代码见 `services/brain/`） |
| 房间（大平层） | 3D 房间，角色的"家"（代码见 `services/house/`） |
| 画廊 | 角色产出的画作与过程展示（代码见 `services/gallery/`） |
| 控制台 / 整合页 | 一页总览所有状态（代码见 `services/console/`） |
| IM 通道 | 经 AstrBot + NapCat 接 QQ（QQ 本体由使用者自行安装） |
| 灾后复活系统 | 定期整包备份 + 分片上传云端 + 换机一键恢复（代码见 `tools/nirvana/`） |

`code/` 是完整的参考实现代码（保持原始目录结构）；`services/` 是可运行的最小示例，可先跑起来感受效果。

## 快速开始

完整步骤见 **`docs/配置清单.md`**（从下载到跑起来的 6 步），核心三步：

1. **装环境**：按 `docs/模型需求清单.md` 把 Python 3.12、Ollama、ffmpeg、AstrBot 装好（也可以用配置向导里的「自动装机」）；
2. **备账号**：按 `docs/登入清单.md` 逐项准备你自己的账号与密钥（DeepSeek API Key 等）；
3. **一键配置 + 启动**：双击根目录 **`一键配置.cmd`**，浏览器里点「⚡ 一键自动配置」（或命令行 `python configure.py`），完成后双击 **`打开入口.cmd`** 开始使用。

> 模块关系与数据流见 `docs/架构总览.md`；各页面设计见 `docs/界面设计.md`。

## 素材导入

Live2D 模型、表情包、视频通话背景、桌宠形象都需要使用者自备（本项目不附带任何角色形象素材）。打开 **`一键配置.cmd`** → 页面里的 **「🎨 素材导入」** 可以直接导入：

| 素材 | 导入位置 |
|---|---|
| Live2D 模型（.moc3 + .model3.json + 贴图文件夹） | `code/video/static/live2d/` |
| 表情包 | `code/assets/stickers/` |
| 视频通话背景（图片/视频） | `code/video/static/backgrounds/` |
| 桌宠形象 | `code/app/petweb/whale/` |
