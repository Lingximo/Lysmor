# 灾后复活系统（备份 / 恢复工具）

机器会坏，伴侣不该跟着消失。这套工具负责：**定期整包备份 → 分片上传云端 → 换机一键恢复 → U 盘应急包**。

## 文件

| 文件 | 作用 |
|---|---|
| `build.py` | 把记忆库/代码/配置/状态/说明书打成整包（附逐文件 sha256 清单） |
| `upload.py` | 切 16MB 分片上传云端，传完核对，保留最近 7 套；**需先接网盘接口** |
| `restore.py` | 校验 → 解包 → 铺回原位（`--file` / `--live` / `--auto`） |
| `check.py` | 自检：这套东西是不是完整的（退出码 0/1/2） |
| `audit.py` | 环境体检：这台机器和包里的环境差多少 |
| `kit.py` | 生成 U 盘应急包（整包 + 脚本 + 说明书） |
| `export_env.py` | 导出 requirements.txt + 计划任务 XML |
| `expected_env.json` | 环境期望值（audit.py 读它） |

## 部署（第一次）

1. 把本目录整个拷进你的**数据目录**（与 `memory/`、`code/` 同级）；
2. 逐个打开脚本，把顶部"部署时按需修改"的路径改成你的实际路径；
3. 跑 `python check.py` 确认能识别你的目录结构；
4. 跑 `python build.py` 打出第一份整包；
5. `upload.py` 里按顶部说明接入你自己的网盘 API（不接也能本地验证分片逻辑）。

## 建议的节奏

- 计划任务每 2 天跑一次 `upload.py`（自带打包）；
- 云端保留 7 套（≈14 天），旧套自动清理；
- 出一份 `kit.py --usb <U盘>` 的应急包，插上 U 盘它就更新。

## 包里有什么 / 没有什么

- **有**：记忆库、代码、配置（可能含密钥）、状态、启动脚本、交接文档。
- **没有**：模型权重、第三方软件、日志、缓存——这些可重新下载，装的时候现拉。

## 安全

包里有密钥和账号凭据：**只放自己的私有云盘 / U 盘，不要外传。**
发布本仓库前，跑一遍根目录 `SECURITY.md` 的自查命令。
