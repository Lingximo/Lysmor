# 画廊（services/gallery）

角色产出的画作按时间陈列：网格 + 详情。

## 启动

```
python server.py --port 8002 --token 你自己的口令
```

- 浏览器打开 `http://127.0.0.1:8002/?t=你的口令`；
- 点击作品看大图与说明。

## 数据

- 清单在 `data/index.json`：每件作品 = 标题 + 说明 + 日期 + 图片文件名（`process` 字段已预留，播放过程视频将在后续版本实现）；
- 图片/视频放 `media/`，服务端只允许访问这个目录内的文件（防目录穿越）；
- 本骨架自带 3 张**抽象占位图**（自己画的渐变/几何 SVG），不含任何角色形象素材；
- 接你自己的画画系统：把产出图放进 `media/`、在 `index.json` 登记一条即可。

## 文件

| 文件 | 作用 |
|---|---|
| `server.py` | 清单 + 媒体服务（纯标准库，路径安全校验） |
| `data/index.json` | 作品清单示例 |
| `media/*.svg` | 占位示例图 |
| `static/index.html` / `style.css` / `app.js` | 画廊页 |
