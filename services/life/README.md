# 生命面板（services/life）

一组带"半衰期回稳"的生理/情绪状态，随时间自行演化；面板**只读**。

## 启动

```
python server.py --port 8005 --token 你自己的口令
```

- 不加 `--token` 自动生成开发口令并打印；
- `--demo` 把时间加快 60 倍，方便看曲线动起来（演示用）；
- 浏览器打开 `http://127.0.0.1:8005/?t=你的口令`。

## 设计

- 六项状态：精力 / 饥饿 / 口渴 / 困意 / 情绪 / 压力；
- 每项 = 基线 + 半衰期回稳 + 漂移（饥饿随时间上升等）+ 扰动；
- 状态落盘到 `state.json`（可进灾后复活包的 `state/`）；
- HTTP 面只有 `GET /api/state` 和 `GET /api/trend`——**没有**任何改写入口。

## 接真实事件

吃饭、喝水、互动、睡觉这些"真实事件"由外部系统喂进来：
在 `server.py` 里用内部接口 `MODEL.change("hunger", -0.4, "吃了饭")`。
事件源可以是机器人框架的插件、聊天、陪玩等——面板本身永远只读。

## 文件

| 文件 | 作用 |
|---|---|
| `server.py` | 状态引擎 + 服务端（纯标准库） |
| `static/index.html` / `style.css` / `app.js` | 仪表卡片 + 趋势曲线 |
| `state.json` | 状态落盘（运行时自动生成，已被 .gitignore 屏蔽） |
