# 大平层（services/house）

一个可旋转/缩放的等距投影 3D 房间骨架。

## 启动

```
python server.py --port 8007 --token 你自己的口令
```

- 浏览器打开 `http://127.0.0.1:8007/?t=你的口令`；
- 交互：**拖拽旋转视角、滚轮缩放、点击家具看说明**。

## 设计

- 房间尺寸与家具布局全在 `data/plan.json`（坐标单位米）；
- 家具 = 位置 + 尺寸 + 展示色 + 说明文字；
- 居住者只是**一个通用光点占位**（`plan.json` 里的 `occupant`）——
  形象素材（立绘/Live2D/3D 模型）由使用者自备，本骨架不附带任何角色形象；
- 渲染用 Canvas 2D 等距投影、零依赖；要光照/贴图/模型，把前端换成 Three.js 即可。

## 接真实状态

房间页是只读展示。要显示真实状态（居住者在哪、在做什么），由外部系统
改 `data/plan.json` 的 `occupant` 字段，或自己加一个状态接口。

## 文件

| 文件 | 作用 |
|---|---|
| `server.py` | 布局读取 + 服务端（纯标准库） |
| `data/plan.json` | 房间与家具布局示例 |
| `static/index.html` / `style.css` / `app.js` | 3D 房间页（Canvas） |
