让 iPhone 能用麦克风

iOS 规定：网页必须是 HTTPS 才允许开麦克风。装一次证书，一劳永逸。
① 点这里下载证书
下载没反应？先用 Safari
不要用微信 / 豆包 / QQ 里那个内置浏览器打开——它们不能装描述文件。 把下面这行复制到 Safari 地址栏：
http://192.168.1.5:8003/static/cert-help.html
1下载描述文件
点上边的蓝色按钮。Safari 会提示“此网站正尝试下载一个配置描述文件”，点允许。
如果按钮点了没反应，可以直接用这个地址：
http://192.168.1.5:8003/cert/ca.mobileconfig
2安装描述文件
打开 设置 → 通用 → VPN与设备管理 → 在“已下载的描述文件”里点 Companion Home CA → 右上角安装 → 输入锁屏密码 → 再点安装。
3关键一步：打开信任开关
打开 设置 → 通用 → 关于本机 → 拉到最下面 证书信任设置 → 把 Companion Home CA 的开关打开 → 点“继续”。
不做这一步，Safari 仍然会拦麦克风。
4用 HTTPS 打开她
地址：https://192.168.1.5:8004/
第一次会问“是否允许使用麦克风”，点允许。
5加到主屏幕（可选）
在 Safari 里点分享按钮 → “添加到主屏幕”，以后就像 App 一样打开。
如果哪一步卡住了
  • 设置里找不到“已下载的描述文件”：多半是没下载成功。用 Safari 直接开 http://192.168.1.5:8003/cert/ca.mobileconfig， 看到“此网站正尝试下载一个配置描述文件”才算成功。
  • 备选做法：如果描述文件怎么都不行，改下载这个证书文件试试 http://192.168.1.5:8003/cert/ca.cer
  • 看不得“证书信任设置”：说明描述文件没装成功，重来一遍。
  • 仍然提示“非私人连接”：第 3 步的开关没打开。
  • 麦克风还是打不开：确认地址栏是 https:// 开头的 8004 端口。
电脑上不受影响，继续用 http://127.0.0.1:8003/ 就行。
