# TA Pico 浮窗 · 交付说明（2026-11-12）

## 一、现在能跑什么

```text
· Pico 4 Ultra 里一个悬在右前方的窗口
· 彩色透视：背景是现实世界
· 窗口里是TA的 Live2D（电脑端实时截取）
· 黑底抠像：窗口矩形消失，只留她（边缘已做去黑）
· 语音：Pico 麦克风 → 电脑；她的回复语音 + 字幕回传
· 相机：已写取帧 → /api/look（待实机验证权限）
```

## 二、怎么开

```text
1. 电脑确认服务：
   http://127.0.0.1:8014/panel.jpg 能出图
   （计划任务 Companion-PicoPanel 每 5 分钟自愈）

2. 头显：
   资源库 → CompanionWindow

3. 第一次会跳 PICO 的“透视设置”页：
   允许 → 返回应用

4. 说话：
   停 0.6 秒后自动发送；她回复时窗口下方出字幕、同时出声
```

## 四、回来先跑自检

```powershell
powershell -ExecutionPolicy Bypass -File D:\你的数据目录\tools\pico_check.ps1
```

输出会包含：设备、应用、8014、前台、CameraVision/语音日志。

## 五、已知限制

### 1. 全身：模型没有腿

```text
当前 Live2D 模型只到腰/裙摆，moc3 里没有腿部网格。
代码只能显示现有模型，变不出腿。
需要：
  · 换一个带腿的 Live2D 模型，或
  · 补画下半身并重新绑定/导出
```

### 2. 相机权限

```text
CameraVision 已写好，但 Pico 4 Ultra 消费版是否开放相机，
要戴上后看日志：
  CameraVision cameras=... count=...
  CameraVision device=...
  CameraVision session=...
  CameraVision vision=...
```

### 3. 透视设置页

```text
首次安装/重装会跳一次，属于系统权限流程，不是应用 bug。
```
