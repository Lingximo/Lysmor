# HaloFlux 办公室宠物

在 DSH 页面里常驻一个 HaloFlux 办公室悬浮窗。六名员工（导演、架构师、实现、评审、跑腿、翻译）和一张任务看板，跟着她的每一轮对话动起来：收到你的消息 → 导演接「对话」任务、亮起来；答完 → 回待机。

## 用起来

- 悬浮窗默认在右下角，拖标题栏可以挪位置；位置、大小、折叠状态记在浏览器本地，下次打开还是老样子。
- 标题栏三个按钮：`⟳` 刷新画面、`—` 折叠成一条、`×` 收起。
- 收起后右下角留一个 🏢 圆钮，点一下重新展开。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 显示办公室悬浮窗 |
| `width` | `520` | 悬浮窗宽度（像素） |
| `height` | `340` | 悬浮窗高度（像素，不含标题栏） |
| `startHidden` | `false` | 启动时只留右下角按钮 |

## 它怎么算出来的

插件的 Host 段直接监听 DSH 的会话回合事件（`turn/start` / `turn/end`，子 Agent 不计），在内存里维护员工状态和步骤记录，再通过 `/dsh-office/state` 与 `/dsh-office/events`（SSE）提供给悬浮窗。不读写记忆库，不改她的人设和生理状态。

## 限制

- 状态是进程内的：DSH 重启后看板从干净的一轮开始，不留历史（旧版本存在 `board.db` 里，这个版本有意不落盘）。
- 安装或升级后在页面刷新一次才会出现；端口/页面地址变化时会自动跟着变化，因为资源都走 DSH 自己的 webServer。
- 只在本机回环请求上提供资源，局域网其他机器打不开 `/dsh-office/*`。
